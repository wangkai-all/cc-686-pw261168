# 尺寸迁移 · 工件抽检分布分析

把工件尺寸抽检做成二维分布比较工具：先对齐每个样本行长/宽的单位，再比较两批在二维尺寸空间里的分布形状，并用**完整最小费用运输 LP** 计算“把一批的占比搬到另一批至少需要多大调整”，把每条搬移关系画在网格上。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # 19 个单元测试（含独立最短路 oracle 对照）
npm run build      # tsc -b + vite build
npm run preview    # 预览生产构建
```

数据由 `python3 -I scripts/gen_data.py` 确定性生成（固定种子 20261122），输出到 `public/data/`；重复运行结果逐字节一致。

## 三个本地场景

| 场景 | 验证什么 |
| --- | --- |
| `bimodal` 同均值 · 双峰错位 | 两批加权均值都精确等于 (130, 90) mm，两峰沿相反对角线摆放；均值差 ≈ 0，但运输代价约 32 |
| `units` 单位混记 | B 批混用 cm、in、cm/mm；原始数值均值差约 114，按行内单位对齐后长均值只差约 2.7 mm |
| `offset` 宽度偏移 | B 批宽向整体 +8 mm；另含超程、缺测、零权重三行特殊样本 |

## 口径

- **单位**：逐行按 `length_unit` / `width_unit` 换算到 mm（um/mm/cm/m/in），再由页面设定的“1 分析单位 = 多少 mm”换算成分析单位。长、宽两轴分别设置；**绝不按当前批次重新标准化**，真实偏移保留。
- **归一化**：每批按自身有效权重归一化到 1，比较的是分布形状；件数与抽检数量差不会直接变成分布差。
- **网格**：名义量程 → N×N 格。空格不参与供需，也不参与运输距离；同格样本先聚合再搬移，距离按格心计算。
- **超程**：保留真实坐标。默认“排除”只比较量程内样本，并显示被排除的数量与权重；“扩展网格纳入”按同样格宽向外扩格，不把超程样本压到边界，图中用黄色圆环标出。
- **特殊行**：缺测行没有网格位置；无效权重（≤0）单列；编号冲突与未知批次单列。全部可在“逐条审计”表与 CSV 导出中追溯。

## 求解与核对

`src/lib/transport.ts` 用逐次最短路最小费用流求解 dense 二分运输网络（S→源格→目标格→T），Dijkstra 跑在 Johnson 势的既约费用上。结束后逐项核对：

- 供给总和、需求总和、实际送达均为 100%；
- 逐行/逐列守恒误差 < 1e-9；
- 原始代价与对偶代价相对差 < 1e-9；
- 所有既约费用 ≥ 0（最优性证书）。

`tests/reference.ts` 是一个独立的 Bellman-Ford/SPFA 最小费用流 oracle，测试用它在小网格上逐例对照最优值。

## 页面交互

- 点选任一有质量的格 → 右侧列出该格分去了哪些目标格（质量、占比、距离、对角保留）；
- 切换网格分辨率（6–20）或距离尺度（欧氏/曼哈顿/切比雪夫）→ 最优流整体重算，代价变化直接可见；点选按物理 mm 坐标保留，不会漂移；
- 修改长/宽轴量纲 → 只改变“多远算远”，不改变样本坐标与占比；
- 三张明细表（运输流、网格聚合、逐条审计）均可导出 CSV（UTF-8 BOM，Excel 可直接打开）。
